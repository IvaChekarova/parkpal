# ParkPal

ParkPal is a smart parking discovery and reservation mobile application.

## Tech Stack
- Frontend: React Native (Expo)
- Backend: Node.js + Express
- Database: PostgreSQL
- Real-time: Socket.io
- IoT: Raspberry Pi Pico W

## Features (MVP)
- User authentication
- View available parking spots
- Parking details
- Reservation system
- User profile

## Project Structure
- /frontend → mobile app
- /backend → API and server logic
- /docs → diagrams, documentation
